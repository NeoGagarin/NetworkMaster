## UBNT-SEC-001 — Vendor default credential

Severity: **Critical** · Category: **Security** · Confidence: **Certain**

Families: AirOs, EdgeOs

The assigned profile matches the vendor default username and password. Anyone familiar with the device can guess these credentials. Replace them with a unique password in a maintenance window and enter the new profile here. Scan again and confirm this finding clears.

## UBNT-SEC-002 — Public management address

Severity: **High** · Category: **Security** · Confidence: **Certain**

Families: AirOs, EdgeOs

The enrolled management address is public. Internet exposure increases the chance of unauthorized access if upstream filtering allows it. Put management on a private network or restrict access to trusted source addresses. Verify the upstream access policy and management reachability from outside the network.

## UBNT-SEC-003 — Unencrypted web management

Severity: **High** · Category: **Security** · Confidence: **Certain**

Families: AirOs, EdgeOs

HTTP management is enabled without confirmed HTTPS, or HTTPS is explicitly disabled. HTTP sends login information without transport encryption. Enable HTTPS and disable HTTP if the platform supports it. Verify the secure URL and scan again.

## UBNT-SEC-004 — Telnet enabled

Severity: **High** · Category: **Security** · Confidence: **Certain**

Families: AirOs, EdgeOs

Telnet is enabled on this device. Its traffic, including passwords, travels without encryption. Disable Telnet and use SSH for terminal access. Confirm SSH works before disabling Telnet and verify the next scan.

## UBNT-SEC-005 — Default SNMP community

Severity: **High** · Category: **Security** · Confidence: **Certain**

Families: AirOs, EdgeOs

SNMP is enabled with the default public or private community. These well-known values can expose monitoring data or permit writes where configured. Replace the community and restrict SNMP to your monitoring hosts. Verify polling with the replacement value and scan again.

## UBNT-SEC-006 — UPnP enabled on router

Severity: **Medium** · Category: **Security** · Confidence: **Certain**

Families: AirOs, EdgeOs

UPnP is enabled on a router. Clients may create inbound mappings that bypass the intended access policy. Disable UPnP unless there is a documented operational requirement. Check the remaining mappings and verify needed applications still work.

## UBNT-SEC-007 — Discovery enabled on WAN router
